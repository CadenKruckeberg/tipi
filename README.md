# Tipi

My Linux home anywhere; dotfiles, packages, and scripts on any machine or distro.

- Core (functional) dotfiles managed with GNU Stow.
- Dotfiles for theming managed with a custom script and GNU Stow.
- Packages managed by [nip](https://github.com/CadenKruckeberg/nip).
- Other scripts for connecting to my own VPN, mounting my NAS, etc.
- [Nix-system-graphics](https://github.com/soupglasses/nix-system-graphics) flake
for graphical Nix packages on any distro.
